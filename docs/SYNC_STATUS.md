## 保留在本地的内容

- 完整游戏包、完整资源快照、完整缓存和生成的运行清单。
- `viewer.local.json`、本机服务日志、依赖目录、快捷方式。
- 临时逆向探针、实验性工程及依赖完整缓存的历史资源验收测试。

固定资源表只记录指纹与相对目录约定。不同来源的资源不会自动替换为作者的快照；自备资源需要按运行手册配置。

## 发布检查

每次主线推送均运行现有 Pages 构建和浏览器回归。新增 `Local source checks` 工作流检查 Python 依赖、源码编译、服务器入口及 50 项独立测试。

五套小游戏可以直接针对仓库内的精选资源运行检查，无需完整游戏缓存：

```powershell
cd web
$env:CROSSCORE_OFFLINE_ROOT = '../pages-pack/public'
node check-offline-ui.mjs
```

本地完整版需要用户提供资源及运行清单。源码导入、构建和临时服务启动已验证；全新电脑完整空缓存重建仍未完成验证。
