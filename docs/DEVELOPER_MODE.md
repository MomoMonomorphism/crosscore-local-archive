# 开发者模式

本地版和 GitHub Pages 演示版共用这套工具。在线演示仅能检查演示包中已有的资源。

## 入口与两个窗口

1. 点击左上角 **CC** 切换到开发者模式，再点击顶部的“开发工具”。
2. “点选与调整”用于检查选中对象；“图层与遮罩”以磁贴展示当前画面的资源。两个窗口可以独立拖动、收起和关闭，画布仍可操作。
3. “当前画面”默认跟随可见画面，也可手动选择角色、动作素材、插画、ASMR 或互动界面。

## 查看与调整

- 开启“点选画布图层”，点击画面检查该位置的素材；使用“重叠候选”切换前后的图层。点选期间会拦截游戏操作，按 Esc 退出点选。
- “跟随点选”默认开启，会在磁贴窗口定位对应缩略图；也可通过“定位缩略图”手动跳转。
- 磁贴支持图层、槽位和遮罩分类，以及名称、附件、来源搜索。隐藏的对象仍可检查。
- 可调整图层或图像槽位的显示、透明度和独显，也可禁用 Spine 裁切或外部遮罩。透明度是原动画透明度的乘数。
- 黑幕图片与裁切遮罩是不同对象：隐藏黑幕图片会露出下方画面；禁用裁切会显示裁切范围之外的素材。
- 缩略图复用已加载的贴图，按可见范围生成。动作附件和信息是快照，需要查看当前帧时点击“刷新信息”。

点选采用网格或显示区域命中，透明像素也可能进入候选。裁切槽位没有图片，因此显示轮廓或关联信息。工具不提供附件替换和动画时间轴编辑。

## 恢复与预设

- “恢复单项”“恢复当前画面”及“恢复全部画面”可以清除临时调整。
- 再次点击 **CC** 切回普通模式，会清除全部临时覆盖和点选轮廓，关闭开发窗口，恢复原始效果。工具不会改写原资源或动作数据。
- 命名预设按角色、皮肤和画面类型保存到当前浏览器；选择或导入预设后，需要点击“应用”。支持 JSON 导入、导出和删除。
- 临时调整不会随浏览器重启自动应用；保存的预设会保留。模式仅在当前浏览器会话内记忆。
- 内置“随想曲04B动作黑影”预设隐藏已确认的两个黑影槽位，保留画框黑边；对应资源需要在当前版本中可用。

界面动效遵循系统的“减少动态效果”设置。关闭窗口即停止其交互，退出动画不会继续接收操作。
