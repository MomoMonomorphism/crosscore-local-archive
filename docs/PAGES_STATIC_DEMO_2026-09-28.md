# Pages 静态演示包（本地预览）

2026-09-28 的阶段产物是一个独立的静态站点预览，不需要 Python 应用服务器或在线 Lua 会话。浏览器内执行前端、Spine 渲染和五套小游戏的原 Lua；所选清单、图片、语音、ASMR 和场景文件以普通静态文件提供。正式的 `8798` 本地版继续使用原有服务路径。

## 演示内容

- 6 个角色入口，覆盖冕羽、刃齿、波塞冬、伏特加、旋律和赤夕的选定形态；含默认立绘、动态骨骼、已配置的交互与素材预览。
- 4 组关联 CG / 插画档案：皇室聚会、热沙之夏、诱惑配搭、双星乘务。包含静态画面、动态画面、交互语音；后两组还包含姿态切换所需的额外骨骼。
- 1 张冕羽 ASMR 专辑，只保留前 18 秒的音频与对应台词。这是容量受控的功能演示，不是原专辑全文。
- 5 套小游戏的原始 Lua 场景、图片和音效。启动前预载各游戏素材；局内点击、计时和结算在浏览器执行。

当前资源约 720 MB，分别写入 `pages-pack/public/` 与 `dist-pages/`。这些目录、`web/public/offline/` 和本机缓存均被 Git 忽略；源码提交不包含游戏资源。

发布候选的许可、独立安装与仓库布局检查见[发布候选说明](PUBLISH_CANDIDATE_2026-09-29.md)。本机忽略这些目录仅为避免误提交；若最终获准公开精选资源，需要将审定后的文件明确纳入干净的公开候选，而不是直接推送当前本地分支。

## 本机生成与验证

需要已有的本机游戏资源、缓存、Python 依赖和前端 Node 依赖。在仓库根目录运行：

```powershell
python tools/prepare_pages_demo.py
Set-Location web
npm ci
Set-Location ..
python tools/collect_web_licenses.py
Set-Location web
npm run build:pages
Set-Location ..
python tools/check_pages_demo.py
python tools/check_pages_release.py --base /
python -m http.server 8799 --directory dist-pages
```

预览地址：<http://127.0.0.1:8799/>。这个服务器仅提供文件；`/api/manifest` 在服务器上不存在，页面请求由静态构建映射到 `static-api/manifest.json` 等文件。若使用仓库型 Pages 地址，在构建前设置 `VITE_BASE_PATH=/<仓库名>/`，让 JS、静态资源与小游戏文件都走仓库子路径。构建产物应作为站点根目录部署。

当前测试通过：前端 TypeScript 类型检查、五套小游戏的 Lua 逻辑检查、原本地时间线回归、静态清单引用完整性检查；静态服务器已抽查首页、清单、Spine、插画、ASMR、小游戏文件均返回 200。用户已在本机 8799 对选定功能做过体验验收；这不代表公开域名和其他网络条件已经验收。2026-09-29 的候选包约 733 MB、735 个文件，未选角色的交互模型和语音索引已从静态 JSON 排除，资源检查会拒绝未被引用的游戏文件。

## 发布前

这是技术预览，不是已获素材发布许可的公开版本。公开 GitHub Pages 前需要确定哪些游戏图片、音频、台词和脚本可以再分发，并核对第三方运行库的声明。还需检查静态包的实际带宽、下载体验和仓库容量；若演示资源继续增长，应再缩减或更换资源交付方式。历史[发布准备审计](RELEASE_READINESS_2026-09-27.md)描述的是本地服务架构，本文记录其后新增的静态路线。
