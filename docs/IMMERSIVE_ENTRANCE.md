# Immersive menus and entrance playback

Immersive menus now open and close manually. Clicking the picture leaves them open. Shared tabs and a scrollable body keep controls reachable on smaller screens; ASMR includes seeking, speed, volume, full/preview tracks, album selection and transcript navigation. Illustration menus include picture selection, display controls and voices.

The “自动播放入场” toggle is available in the gallery toolbar’s overflow menu and immersive settings. It defaults to on and persists in local storage. Turning it on applies to the next selection; manual replay stays available when it is off. Entry playback starts only after its configured skeleton and interaction resources are ready.

Local mode reads entrance data for the selected model and reuses cached results. Resource downloads and decoding overlap configuration preparation; independent scene layers load concurrently while retaining authored layer order. Pages reads its existing prebuilt full table and retains stage, portrait and thumbnail loading feedback.

The Pages selection and resource files are unchanged. Browser checks cover delayed/failed/cached loading, entrance preference persistence and replay, and immersive ASMR controls and responsive reachability. Visual and audio fidelity still require comparison with the original game.
